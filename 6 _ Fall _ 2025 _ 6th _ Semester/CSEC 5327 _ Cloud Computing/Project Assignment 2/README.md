# Mitigate Threats and Vulnerabilities with Security Command Center

A completed five-module Google Cloud Security Command Center project covering configuration, finding analysis, application-vulnerability scanning, threat detection, mitigation, and findings export.

## Established Project Modules

1. **Get Started with Security Command Center** - explored the SCC interface, configured project-level settings, and analyzed and corrected vulnerability findings.
2. **Analyze Findings with Security Command Center** - created a continuous export pipeline to Pub/Sub and exported findings for analysis with BigQuery and Cloud Storage.
3. **Identify Application Vulnerabilities with Security Command Center** - deployed a deliberately vulnerable application, enabled Web Security Scanner, identified an XSS vulnerability, corrected it, and scanned again.
4. **Detect and Investigate Threats with Security Command Center** - initiated and mitigated a test threat, configured Event Threat Detection, and managed SCC findings.
5. **Mitigate Threats and Vulnerabilities with SCC: Challenge Lab** - configured the Cymbal Bank environment, created mute rules, analyzed and corrected high-severity findings, used security scanning, and exported findings to Cloud Storage.

## Demonstrated Skills

Security Command Center, Security Health Analytics, Event Threat Detection, Web Security Scanner, Pub/Sub, BigQuery, Cloud Storage, Compute Engine, firewall rules, vulnerability analysis, XSS remediation, finding prioritization, mute rules, investigation, and findings export.
