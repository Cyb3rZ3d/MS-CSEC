# Develop Your Google Cloud Network

A completed Google Cloud project covering identity and access management, data services, VPC networking, monitoring, Kubernetes deployment strategies, and an end-to-end network challenge.

## Established Project Modules

1. **Cloud IAM: Qwik Start** - explored project roles, prepared a Cloud Storage bucket, removed project access, and assigned targeted Storage permissions.
2. **Introduction to SQL for BigQuery and Cloud SQL** - practiced SQL queries, explored BigQuery, created a Cloud SQL instance, and ran Cloud SQL queries.
3. **Multiple VPC Networks** - created custom-mode VPC networks, firewall rules, VM instances, connectivity tests, and a VM with multiple network interfaces.
4. **Cloud Monitoring: Qwik Start** - deployed a Compute Engine instance and Apache server, then configured uptime checks, alerting, dashboards, charts, and log review.
5. **Managing Deployments Using Kubernetes Engine** - completed standard, rolling, canary, and blue-green deployment exercises.
6. **Develop Your Google Cloud Network: Challenge Lab** - built development and production VPCs, a bastion host, Cloud SQL, a Kubernetes cluster, a WordPress deployment, monitoring, and additional engineer access.

## Demonstrated Skills

Google Cloud IAM, Cloud Storage, BigQuery, Cloud SQL, VPC networking, firewall rules, Compute Engine, multi-NIC virtual machines, Cloud Monitoring, Cloud Logging, Google Kubernetes Engine, bastion hosts, WordPress deployment, and least-privilege access.
